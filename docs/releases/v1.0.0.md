# WORK TIME — V1.0.0

Moins de distractions sur YouTube, sans empêcher la lecture.

## Inclus

- Miniatures remplacées par des cartes **WORK TIME**.
- Floutage optionnel du bloc complet : titre, chaîne, avatar, vues, date et badges.
- Accueil, recherche, cartes Shorts et recommandations à droite.
- Planning par jour, jusqu’à trois créneaux, y compris après minuit.
- Modes Planning / Toujours actif / Désactivé, et pause de 15 minutes.
- Réglages locaux, aucun compte ou collecte de données par l’extension.

Le lecteur et les informations de la vidéo en cours restent intacts.

## Installation

1. Téléchargez `work-time-v1.0.0.zip` ci-dessous et décompressez-le dans un dossier permanent.
2. Ouvrez `chrome://extensions` et activez le **Mode développeur**.
3. Cliquez sur **Charger l’extension non empaquetée**, puis sélectionnez le dossier contenant `manifest.json`.
4. Épinglez WORK TIME et rechargez les onglets YouTube.

Chrome 120 ou plus. Pas de publication Chrome Web Store à ce stade.

## Vérification

21 tests unitaires et 17 vérifications Chromium réussis. Les captures YouTube publiées dans le README sont des pages locales de test, clairement signalées.

YouTube desktop uniquement. Ce filtre visuel ne bloque pas le réseau ni les publicités sponsorisées. Les changements de présentation de YouTube peuvent demander une mise à jour.
