# Installer WORK TIME V1

Cette archive contient l’extension prête à charger. Aucune commande, compilation ou dépendance supplémentaire n’est nécessaire.

1. Décompressez l’archive dans un dossier permanent.
2. Ouvrez `chrome://extensions` dans Chrome 120 ou plus.
3. Activez le **Mode développeur**.
4. Cliquez sur **Charger l’extension non empaquetée**.
5. Choisissez le dossier qui contient `manifest.json`.
6. Épinglez **WORK TIME**, puis rechargez vos onglets YouTube.

Ne supprimez pas ce dossier après l’installation. L’extension n’est pas publiée sur le Chrome Web Store.

## Commencer

- **Toujours actif** applique immédiatement le filtre.
- **Flouter les informations** atténue le titre, la chaîne, l’avatar, les vues et les autres informations des cartes. Le survol ou le focus clavier les rend lisibles.
- **Mon planning hebdomadaire** permet de définir les jours et les créneaux.
- **Planning** suit ces créneaux ; **Désactivé** rétablit l’affichage normal.
- **Faire une pause de 15 min** suspend temporairement le filtre sans perdre vos réglages.

Par défaut : lundi à vendredi, 09:00–12:00 et 14:00–18:00, selon l’heure de votre ordinateur.

La vidéo en cours et ses informations restent intactes. Les réglages restent sur votre appareil. Le filtre ne bloque ni le réseau ni toutes les publicités. Voir `PRIVACY.md`.

Pour une mise à jour, remplacez les fichiers du dossier, actualisez l’extension dans `chrome://extensions`, puis rechargez YouTube.

Guide complet, sources et signalements : https://github.com/zerr0o/YoutubeDistractionHider
